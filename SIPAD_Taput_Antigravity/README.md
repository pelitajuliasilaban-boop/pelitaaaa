# SIPAD Taput — Project untuk Antigravity

Proyek ini berisi prototype antarmuka web Sistem Informasi Pendapatan Asli Daerah (SIPAD) Kabupaten Tapanuli Utara.

## Struktur
- `index.html` — halaman utama prototype (HTML, Tailwind CSS CDN, dan JavaScript).

## Cara membuka di Antigravity
1. Ekstrak file ZIP ini ke folder proyek.
2. Buka Antigravity.
3. Pilih **Open Folder** lalu pilih folder `SIPAD_Taput_Antigravity`.
4. Buka `index.html` untuk melihat atau mengedit kode.
5. Untuk melihat tampilan, buka `index.html` di browser. Jika Antigravity menyediakan preview/live server, jalankan dari folder ini.

## Catatan
- Prototype menggunakan data contoh yang ditulis langsung di HTML.
- Tailwind CSS, Google Fonts, dan Material Symbols dimuat melalui CDN, jadi koneksi internet diperlukan untuk tampilan optimal.
- Ini masih prototype frontend; belum terhubung ke database, API pemerintah, sistem pembayaran, atau layanan tanda tangan elektronik sungguhan.
- Data, nominal, identitas, status, dan klaim integrasi yang tampil harus diverifikasi dan diganti dengan data resmi sebelum digunakan dalam sistem nyata.
